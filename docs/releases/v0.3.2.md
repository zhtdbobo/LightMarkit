# LightMarkit v0.3.2

## 版本说明

LightMarkit v0.3.2 修复了文档大纲误收录代码块内 Markdown 标题的问题，使大纲内容与实际文档结构保持一致。

## 修复

- 文档大纲忽略反引号和波浪线代码围栏内的 Markdown 标题。
- 正确处理更长的关闭围栏，较短或不同类型的围栏不会提前结束代码块。
- 未闭合的代码围栏不再导致其中的伪标题出现在大纲中。
