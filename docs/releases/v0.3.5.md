# LightMarkit v0.3.5

## 版本说明

LightMarkit v0.3.5 恢复 Windows 与 macOS 的签名自动更新产物，使 Release 资产结构与 LightTodo 保持一致。

## 构建与更新

- Windows 生成 x64 NSIS 安装包、更新签名和 `latest.json`。
- macOS 生成 Universal DMG、Universal 应用更新压缩包和更新签名，同时兼容 Intel 与 Apple Silicon。
- `latest.json` 包含 Windows、`darwin-aarch64` 和 `darwin-x86_64` 更新信息。
- 更新包下载通过 `gh-proxy.com`，应用仍使用内嵌公钥验证签名。
- macOS DMG 不使用 Apple Developer ID 签名或公证，首次打开时可能出现 Gatekeeper 提示。

## 下载

- Windows x64：NSIS `.exe`
- macOS Intel / Apple Silicon：Universal `.dmg`
- Windows 自动更新：NSIS `.exe` 与 `.sig`
- macOS 自动更新：Universal `.app.tar.gz` 与 `.sig`
- 更新清单：`latest.json`
