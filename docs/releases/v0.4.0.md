# LightMarkit v0.4.0

## 版本说明

LightMarkit v0.4.0 是新的稳定版本，汇总现有 Markdown 编辑、实时预览、代码块折叠、导出和应用内更新能力。

## 功能

- 使用 CodeMirror 6 编辑 Markdown，支持行号、文件夹浏览、自动保存和中文快捷命令。
- 实时预览表格、任务列表、本地图片和 Mermaid 图表。
- 预览代码块支持折叠，折叠后显示语言、首个非空代码行和总行数。
- 支持文档大纲、同步滚动以及 HTML、PDF 导出。
- 支持经过签名验证的 Windows 与 macOS 应用内更新。

## 构建与下载

- Windows x64：NSIS `.exe`、更新签名和 `latest.json`。
- macOS Intel / Apple Silicon：Universal `.dmg`、Universal `.app.tar.gz` 和更新签名。
- `latest.json` 包含 Windows、`darwin-aarch64` 和 `darwin-x86_64` 更新信息。
- macOS DMG 不使用 Apple Developer ID 签名或公证，首次打开时可能出现 Gatekeeper 提示。
