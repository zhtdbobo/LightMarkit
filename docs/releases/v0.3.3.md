# LightMarkit v0.3.3

## 版本说明

LightMarkit v0.3.3 修复了编辑器行号显示和更新下载体验，并接入带签名验证的 Tauri Updater。此版本安装后，后续更新可以直接在应用内完成。

## 新增

- 编辑器左侧显示行号栏，当前行号跟随编辑状态高亮。
- 在“关于”界面检查新版本，并在应用内显示下载百分比。
- 下载完成后验证更新签名，以 NSIS 被动模式安装并自动重启应用。

## 改进

- `latest.json` 和安装包通过 `gh-proxy.com` 镜像下载。
- 推送版本标签后自动生成 NSIS 安装包、`.sig` 签名和 `latest.json`，并创建草稿 Release。
- 网络、签名或安装失败时显示对应错误并停止更新。

## 升级说明

- v0.3.2 及更早版本没有内置 Tauri Updater，需要手动安装一次 v0.3.3。
- 安装 v0.3.3 后，后续版本可以通过应用内更新完成升级。

## 下载

- Windows x64 安装包：NSIS `.exe`
- 更新签名：`.sig`
- 更新清单：`latest.json`
