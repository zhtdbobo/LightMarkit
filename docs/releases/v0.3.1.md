# LightMarkit v0.3.1

## 版本说明

LightMarkit v0.3.1 新增了参考 LightTodo 设计的关于界面，并加入基于 GitHub Release 的版本检查和代理下载流程。

## 新增功能

- 顶部菜单新增“关于”入口。
- 关于界面展示应用图标、版本、产品简介、主要特点和开源许可。
- 支持打开 LightMarkit GitHub 项目主页。
- 支持检查 GitHub 最新 Release，并比较当前版本与远端版本。
- 发现新版本后可直接下载对应的 Windows x64 安装包。

## 体验改进

- 关于界面适配明暗主题和窄窗口布局。
- 当前版本已是最新版时显示明确提示，不提供重复下载按钮。
- 检查更新和打开下载地址失败时显示可读的错误信息。
- 使用 `gh-proxy.com` 代理地址下载 GitHub Release 安装包。

## 安全

- 内容安全策略仅额外允许连接 GitHub Release API。
- Tauri 外链权限仅允许项目主页和 LightMarkit 版本化安装包地址。

## 下载

- Windows x64 安装包：NSIS `.exe`
