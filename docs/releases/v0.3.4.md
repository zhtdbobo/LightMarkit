# LightMarkit v0.3.4

## 版本说明

LightMarkit v0.3.4 为预览代码块增加折叠摘要，并把自动发布流程扩展为 Windows 与 macOS 双平台构建。

## 新增

- 预览区的普通代码块支持折叠和展开。
- 折叠状态显示代码语言、首个非空代码行和总行数，长首行自动省略。
- 折叠状态在当前文档实时刷新后保持不变。

## 构建与发布

- Windows 构建生成 x64 NSIS 安装包。
- macOS 构建生成 Universal DMG，同时兼容 Intel 和 Apple Silicon。
- macOS DMG 不使用 Apple Developer ID 签名或公证，首次打开时可能出现 Gatekeeper 提示。
- 发布工作流校验标签、README、前端、Rust 与 Tauri 配置中的版本号。
- Windows 和 macOS 更新信息必须同时写入 `latest.json`，否则发布任务失败。

## 下载

- Windows x64：NSIS `.exe`
- macOS Intel / Apple Silicon：Universal `.dmg`
- Tauri 更新签名：`.sig`
- 更新清单：`latest.json`
