# LightMarkit v0.4.2

## 版本说明

LightMarkit v0.4.2 修复 macOS 从访达打开 Markdown 文件无响应的问题，并区分本地安装包构建与正式更新产物签名流程。

## 修复

- macOS 支持从访达双击 `.md`、`.markdown` 文件直接使用 LightMarkit 打开。
- macOS 的“打开方式”会唤醒 LightMarkit 并载入目标文件。
- 应用冷启动和已运行状态都会处理系统发送的文件打开事件。

## 构建改进

- 新增 `pnpm tauri:build:local`，无需自动更新签名私钥即可生成本地安装包。
- `pnpm tauri build` 与 GitHub Actions 发布流程继续生成签名更新包，更新验证策略保持不变。

## 构建与下载

- Windows x64：NSIS `.exe`、更新签名和 `latest.json`。
- macOS Intel / Apple Silicon：Universal `.dmg`、Universal `.app.tar.gz` 和更新签名。
- macOS DMG 未使用 Apple Developer ID 签名或公证，首次打开时可能出现 Gatekeeper 提示。
