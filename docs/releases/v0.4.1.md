# LightMarkit v0.4.1

## 版本说明

LightMarkit v0.4.1 完善编辑与预览体验，并重点修复 macOS 原生窗口、快捷键和系统菜单适配。

## 新增与改进

- 文档大纲支持按标题层级折叠，编辑与预览跳转会将目标标题精确置顶。
- 编辑区代码块支持语言选择、语法高亮、复制和折叠，预览代码块保留原始缩进与横向滚动。
- 所见即所得表格提供跟随当前单元格的行列操作菜单。
- Markdown 预览新增脚注支持，并增强任务列表与 Mermaid 错误展示。
- macOS 改用系统原生标题栏、红黄绿窗口按钮和顶部应用菜单栏。
- macOS 应用级快捷键使用 `⌘`，Windows 继续使用 `Ctrl`。
- 系统托盘菜单支持打开、保存、导出、设置以及显示、隐藏和退出应用。

## 修复

- 修复编辑与预览切换时源码位置和滚动布局发生跳动的问题。
- 修复多行代码块样式断裂、折叠按钮缺失和回车新增代码行样式不连续的问题。
- 修复单个 Mermaid 图表失败时影响其他图表渲染的问题。
- 未修改文档不再因切换视图、窗口失焦、关闭或显式保存而刷新文件时间戳。

## 构建与下载

- Windows x64：NSIS `.exe`、更新签名和 `latest.json`。
- macOS Intel / Apple Silicon：Universal `.dmg`、Universal `.app.tar.gz` 和更新签名。
- macOS DMG 未使用 Apple Developer ID 签名或公证，首次打开时可能出现 Gatekeeper 提示。
